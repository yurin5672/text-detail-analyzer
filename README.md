# 작품 정밀 분석기

웹소설(또는 다른 글)을 AI에게 읽혀서 **장르·분위기를 판별하고, 170개 지표로 채점해 등급과 개선안을 뽑아주는** 단일 HTML 도구입니다.
서버·설치 없이 `작품_정밀_분석기.html` 파일을 브라우저로 열면 바로 실행됩니다.

> ⚠️ **이 프로젝트의 코드는 AI(Claude)가 작성했습니다.** 사람이 요구사항을 정하고 대화로 수정했으며, 코드 전체를 직접 검수하지는 않았습니다. 사용 전 코드를 확인하고, 문제가 있으면 이슈로 알려주세요.

## 기능

- **기계 계산 통계**: 글자 수, 평균 문장 길이, 긴 문장 비율, 대사 비율, 어휘 다양성, 반복어, 예상 읽기 시간 등을 브라우저에서 직접 계산 (AI 분석에도 참고 자료로 전달)
- **프로필 판별**: 주장르, 세부장르, 분위기, 시점, 타깃 독자, 로그라인, 글에서 발견된 서사 기법·용어
- **170개 지표 채점** (15개 영역): 훅·몰입, 서사·구성, 인물, 대사, 문장·문체, 가독성·기술, 세계관·설정, 장르·클리셰, 감정·주제, 상업성, 시점·서술, 독자 경험·심리, 장면·연출, 톤·완성도, 회차 연계
  - 지표마다 점수, 본문 인용, 판단 근거, 수정 팁 제공. 영역마다 총평·잘한 점·개선안 제공
- **종합 평가**: S~F 등급과 100점 점수, 한 줄 평결, 강점, 약점(본문 인용 + 고쳐 쓴 예시 문장), 우선순위 액션 플랜, 예상 독자 반응, 레이더 차트, 가장 약한/강한 지표 TOP 10
- **작품에 맞춘 평가**: 장르·분량에 따라 영역별 가중치가 달라지고, 몰입·감정 점수가 높으면 가독성·기술 항목의 가중치를 낮춰 사소한 흠을 봐주는 보정이 적용됨
- **내 서재**: 여러 작품과 회차를 이 기기(브라우저 IndexedDB)에 자동 저장. 작품별로 회차를 나눠 목록으로 보고, 순서 변경·이름 변경·삭제 가능
- **회차 연계 분석**: 같은 작품의 앞 회차 요약을 다음 회차 분석에 함께 넣어 설정 일관성, 복선 회수, 인물 변화, 전개 속도, 회차 엔딩-시작 연결 등을 평가
- **작품 전체 탭**: 회차별 점수 추이 그래프, 회차 × 영역 점수표, 작품 전체 종합 분석(반복되는 약점, 성장 추세, 다음 회차 제안)
- 결과는 탭(요약 / 개선점 / 영역별 상세 / 프로필·통계)으로 나뉘고, 지표는 접고 펼 수 있으며 "60점 미만만" 필터를 지원
- 결과 텍스트 복사, 서재 전체 JSON 백업·불러오기

## 사용법

1. 저장소를 받거나 `작품_정밀_분석기.html`을 다운로드합니다.
2. 파일을 브라우저(Chrome 등)로 엽니다.
3. **API 설정**에서 제공자, 모델명, API 키를 입력합니다.
4. 본문을 붙여 넣고 **정밀 분석 시작**을 누릅니다.

### 지원하는 API

- **Google Gemini**: [Google AI Studio](https://aistudio.google.com)에서 키 발급. 기본 모델명은 `gemini-flash-latest`
- **OpenAI 호환 Chat Completions**: API 주소, 모델명, 키를 직접 입력

> 모델명은 시간이 지나면 종료될 수 있습니다. 모델 오류가 나면 해당 서비스의 최신 모델명을 확인해서 바꿔주세요.

## 알아둘 점

- **API 키는 브라우저에서 해당 API 서버로만 전송**되며, 별도 서버는 없습니다. 공용 PC에서는 사용 후 키를 지우고, 키를 코드에 적어서 공개 저장소에 올리지 마세요.
- 입력한 본문은 선택한 AI 서비스로 전송됩니다. Gemini 무료 티어는 입력·출력이 모델 개선에 쓰일 수 있으니, 미공개 원고라면 각 서비스의 약관을 확인하세요.
- 점수는 "연재 플랫폼 평균 수준을 50으로 본 AI의 상대 평가"입니다. 객관적 지표가 아니라 참고용 의견이며, 같은 글도 실행할 때마다 결과가 조금씩 달라질 수 있습니다.
- 1회 분석에 API 요청이 17번 나가고 2~5분쯤 걸립니다. 무료 키는 분당·일일 한도에 걸릴 수 있고, 서버 혼잡(503, 429) 오류는 자동으로 재시도합니다. 실패한 영역은 카드의 **재시도** 버튼으로 다시 돌릴 수 있습니다.
- 본문이 너무 길면 모델 입력 한도에 걸릴 수 있습니다. 1화 분량(3천~1만 자)을 권장합니다.
- 일부 OpenAI 호환 서비스는 브라우저 CORS 정책 때문에 직접 호출이 막혀 있을 수 있습니다.

- 데이터는 이 브라우저에만 저장됩니다. 브라우저 데이터를 지우거나 다른 기기·브라우저로 옮기면 사라지니, 중요한 서재는 **서재 백업(JSON)** 으로 보관하세요.
- 회차 연계 평가는 앞 회차가 먼저 분석되어 있어야 동작합니다(회차 순서대로 분석 권장).
